# 🔥 IoT-Based Smart Fire Safety Management System for Smart Home/Office

An IoT-based Smart Fire Safety Management System designed and simulated using **Cisco Packet Tracer**. The system automatically detects smoke, activates emergency devices, and sends notifications to improve fire safety in smart homes and office environments.

---

## 📖 Project Overview

Fire accidents can cause severe damage to property and pose significant risks to human life. This project demonstrates an intelligent fire safety management system that uses IoT devices and automation rules to detect smoke and respond immediately without human intervention.

The simulation is implemented in **Cisco Packet Tracer**, where multiple IoT devices communicate through a **Home Gateway** to provide real-time monitoring and automated emergency response.

## ⚙️ System Workflow

1. Smoke detectors continuously monitor the environment.
2. If the smoke level reaches **0.5 or higher**:
   - Siren turns ON.
   - All three sprinklers turn ON.
   - Smart doors OPEN.
   - Smart windows OPEN.
   - Alarm notification is sent to the smartphone.
3. When the smoke level drops to **0.4 or below**:
   - Siren turns OFF.
   - Sprinklers turn OFF.
   - Doors CLOSE.
   - Windows CLOSE.
   - System returns to normal monitoring mode.

---

## 📐 Automation Rules

| Condition | Action |
|-----------|--------|
| Smoke ≥ 0.5 | Siren ON |
| Smoke ≥ 0.5 | Sprinklers ON |
| Smoke ≥ 0.5 | Smart Doors OPEN |
| Smoke ≥ 0.5 | Smart Windows OPEN |
| Smoke ≥ 0.5 | Mobile Alarm Notification |
| Smoke ≤ 0.4 | Siren OFF |
| Smoke ≤ 0.4 | Sprinklers OFF |
| Smoke ≤ 0.4 | Smart Doors CLOSE |
| Smoke ≤ 0.4 | Smart Windows CLOSE |
